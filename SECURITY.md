# Politique de sécurité

Ne publiez pas une vulnérabilité exploitable dans une issue publique. Utilisez
le formulaire privé « Report a vulnerability » du dépôt GitHub avec la version
de Janus, la plateforme, l'impact et un reproducer minimal.

Les versions pré-1.0 et la dernière version stable reçoivent les corrections
critiques lorsque le défaut concerne la chaîne de distribution, le registre,
le compilateur ou une violation de sûreté mémoire. Les archives officielles
doivent conserver checksums et attestations ; aucune correction ne contourne
les contrôles de provenance.

Un accusé de réception est visé sous sept jours. Le calendrier de divulgation
est coordonné avec le rapporteur et dépend de la disponibilité d'archives
validées sur les trois plateformes tier-1.
