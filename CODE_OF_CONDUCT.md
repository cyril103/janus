# Code de conduite

Les espaces Janus accueillent les contributions sans distinction d'expérience,
d'origine ou d'identité. Les échanges doivent rester précis, respectueux et
centrés sur le travail. Le harcèlement, les attaques personnelles, la
publication d'informations privées et les comportements d'exclusion ne sont
pas acceptés.

Signalez un incident en privé au mainteneur du dépôt. Celui-ci peut avertir,
modérer ou exclure un participant afin de protéger la communauté. Toute
personne chargée d'un signalement doit préserver sa confidentialité.
