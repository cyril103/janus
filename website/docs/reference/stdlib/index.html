std.array

Fournit un tableau dynamique propriétaire et ses opérations séquentielles.

Array conserve les valeurs dans une zone contiguë, agrandit sa capacité
selon les besoins et détruit les éléments encore stockés avec le tableau. Les
accès sont constants; une suppression au milieu et les transformations
complètes sont linéaires.

class Array[T]

Tableau dynamique contigu qui possède ses éléments.

`initialCapacity` réserve de la mémoire sans créer d’élément. Les insertions
déplacent les valeurs dans le tableau; le remplacement, l’effacement et la
destruction appellent `delete` sur les valeurs abandonnées. Les parcours
observants exigent `T <: Copy`, tandis que Array.intoIterator consomme le
tableau et peut transférer des valeurs non copiables.
